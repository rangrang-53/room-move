# 전입신고 가이드

## 전입신고란?
전입신고는 새로운 주소지로 이사한 후 주민등록 주소를 변경하는 절차입니다.

## 신고 기한
- **이사 후 14일 이내**에 반드시 신고해야 합니다
- 기한을 넘기면 과태료(최대 5만원)가 부과될 수 있습니다

## 신고 방법

### 1. 주민센터 방문
- 새 주소지 관할 주민센터 방문
- 필요 서류: 신분증, 임대차계약서(해당 시)
- 처리 시간: 즉시 처리

### 2. 정부24 온라인 신청
- 웹사이트: www.gov.kr
- 공동인증서(구 공인인증서) 필요
- 24시간 신청 가능
- 처리 시간: 1-2일 소요

### 3. 모바일 앱
- 정부24 앱에서 신청 가능
- 본인 인증 필요

## 필요 서류
1. 신분증 (주민등록증, 운전면허증 등)
2. 임대차계약서 (세입자인 경우)
3. 가족관계증명서 (세대주 변경 시)

## 주의사항
- 세대주와 세대원이 다른 주소로 이사하면 각각 신고 필요
- 전입신고 시 자동으로 전출신고도 처리됨
- 확정일자도 함께 받으면 보증금 보호에 유리
