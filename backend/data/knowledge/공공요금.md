# 공공요금 정산 가이드

## 정산이 필요한 요금

### 1. 전기요금
- **한국전력공사 (KEPCO)**
- 연락처: 123 (전화), www.kepco.co.kr
- 이사 당일 계량기 확인 필수
- 정산 방법: 전화, 온라인, 방문

### 2. 가스요금
- **지역 도시가스 회사**
- 이사 전 가스 사용량 검침 요청
- 가스 밸브 잠금 확인
- 안전점검 후 정산

### 3. 수도요금
- **지역 수도사업소**
- 이사 당일 수도 계량기 확인
- 시/군/구청 수도과에서 정산

## 정산 절차

### 이사 1주일 전
1. 각 기관에 이사 예정 통보
2. 해지/이전 신청
3. 최종 검침 일자 예약

### 이사 당일
1. 전기/가스/수도 계량기 사진 촬영
2. 검침원 방문 또는 셀프 검침
3. 가스 밸브 잠금 확인

### 이사 후
1. 최종 고지서 확인
2. 미납 요금 정산
3. 새 주소지에서 개시 신청

## 자동이체 변경
- 기존 자동이체 해지 확인
- 새 주소지 공과금 자동이체 등록
- 청구지 주소 변경

## 주의사항
- 미정산 시 이전 세대 요금 납부 분쟁 발생 가능
- 관리비도 별도 정산 필요 (아파트의 경우)
- 도시가스는 안전점검 필수
