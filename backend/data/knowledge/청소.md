# 이사 청소 가이드

## 청소 시기
- **이사 전**: 기존 집 청소 (원상복구)
- **이사 후**: 새 집 청소 (입주 전)

## 기존 집 청소 체크리스트

### 주방
- [ ] 가스레인지, 후드 기름때 제거
- [ ] 싱크대 배수구 청소
- [ ] 냉장고 자리 청소
- [ ] 타일 벽면 닦기
- [ ] 수납장 내부 비우고 닦기

### 화장실
- [ ] 변기 내부/외부 청소
- [ ] 세면대, 거울 닦기
- [ ] 욕조/샤워부스 물때 제거
- [ ] 환풍기 필터 청소
- [ ] 배수구 머리카락 제거

### 거실/방
- [ ] 바닥 청소 (걸레질)
- [ ] 창문, 창틀 닦기
- [ ] 방충망 세척
- [ ] 에어컨 필터 청소
- [ ] 조명 커버 닦기

### 베란다
- [ ] 바닥 물청소
- [ ] 세탁기 자리 청소
- [ ] 배수구 확인

## 새 집 입주 청소

### 필수 청소
1. 전체 바닥 물걸레질
2. 모든 창문 닦기
3. 화장실 소독
4. 주방 싱크대, 수납장 닦기
5. 붙박이장 내부 닦기

### 해충 방지
- 입주 전 훈증 소독 권장
- 배수구에 트랩 확인
- 문틈, 창문틈 실리콘 처리

## 청소 업체 이용

### 비용 (1인 가구 기준)
- 기본 청소: 5-10만원
- 입주 청소: 10-15만원
- 특수 청소 (곰팡이 등): 15-30만원

### 업체 선택 팁
- 후기 확인
- 보험 가입 여부
- 세제/장비 포함 여부
- AS 정책

## 직접 청소 준비물
- 고무장갑
- 걸레, 청소포
- 다목적 세정제
- 유리 세정제
- 곰팡이 제거제
- 배수구 클리너
- 쓰레기봉투

## 원상복구 기준
- 일반적인 사용으로 인한 오염은 세입자 책임 아님
- 심한 오염, 파손은 청소/수리 비용 공제 가능
- 계약서의 특약사항 확인 필수
