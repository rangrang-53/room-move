# 이삿짐 센터 가이드

## 예약 시기
- **최소 1주일 전** 예약 권장
- 주말, 월말, 계절 이사 시즌(2-3월, 8-9월)은 **2-3주 전** 예약
- 성수기에는 예약이 빨리 마감되니 서둘러야 함

## 이사 종류

### 1. 포장이사
- 업체에서 짐 포장부터 운반, 정리까지 전담
- 가장 편리하지만 비용이 높음
- 1인 가구 기준: 50-100만원

### 2. 반포장이사
- 큰 가전/가구는 업체, 소형 짐은 본인 포장
- 비용 절감 가능
- 1인 가구 기준: 30-60만원

### 3. 일반이사 (용달이사)
- 짐 운반만 업체에서 진행
- 가장 저렴
- 1인 가구 기준: 15-30만원

## 견적 비교 팁
1. **최소 3곳 이상** 견적 비교
2. 방문 견적이 전화 견적보다 정확
3. 추가 비용 항목 확인 (엘리베이터 유무, 층수, 사다리차 등)
4. 파손/분실 보상 조건 확인

## 계약 시 확인사항
- 작업 인원 수
- 차량 크기
- 작업 예상 시간
- 추가 비용 발생 조건
- 보험 가입 여부
- 귀중품 처리 방법

## 이사 당일 준비
1. 귀중품, 중요 서류는 직접 운반
2. 냉장고는 24시간 전 전원 차단
3. 세탁기 급수/배수 호스 분리
4. 분해 필요한 가구 미리 체크

## 주의사항
- 허가받지 않은 업체 주의
- 계약서 반드시 작성
- 짐 파손 시 증거 사진 촬영
- 현금 결제 시 영수증 요청
