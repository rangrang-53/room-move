# 보증금 반환 가이드

## 보증금 반환 시기
- 계약서에 명시된 날짜에 반환
- 일반적으로 **이사 당일** 또는 **잔금 지급일**

## 반환 절차

### 이사 1개월 전
1. 임대인에게 이사 의사 통보 (서면 권장)
2. 보증금 반환 일정 협의
3. 계약서 확인 (특약사항, 원상복구 조건)

### 이사 1주일 전
1. 집 상태 점검
2. 수리 필요 부분 확인
3. 청소 일정 계획

### 이사 당일
1. 임대인과 함께 집 상태 확인
2. 관리비, 공과금 정산
3. 열쇠 반납
4. 보증금 입금 확인

## 공제 항목

### 공제 가능
- 미납 월세, 관리비
- 세입자 과실로 인한 파손 수리비
- 원상복구 비용 (벽지, 장판 등)
- 청소비 (특약 있는 경우)

### 공제 불가
- 자연 노후화 (변색, 마모 등)
- 입주 전부터 있던 하자
- 시설물의 감가상각

## 분쟁 해결

### 보증금을 돌려주지 않을 때
1. 내용증명 발송
2. 주택임대차분쟁조정위원회 신청
3. 임차권등기명령 신청
4. 소액사건 소송 (2,000만원 이하)

### 증거 확보
- 입주 시/퇴거 시 사진 촬영
- 계약서 사본 보관
- 월세, 관리비 납부 영수증
- 대화 내용 기록

## 확정일자와 전세권
- 확정일자: 주민센터에서 무료 받기 가능
- 전세권 설정: 등기소에서 등기
- 우선변제권 확보로 보증금 보호

## 주의사항
- 보증금 반환 전 이사하면 협상력 약화
- 임대인 연락처, 계좌번호 미리 확인
- 원상복구 범위 명확히 협의
